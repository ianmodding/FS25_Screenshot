# Photo Mode

A free-camera photo mode for **Farming Simulator 25**. Set up the scene, fine-tune the image, and capture screenshots in-game.

## Features

- Free camera with adjustable movement speed, mouse-wheel zoom, and a zoom reset.
- In-game environment controls for time, weather, and season.
- Live color grading controls for contrast, brightness, saturation, temperature, gamma, and shadows.
- Depth of field with adjustable focus distance and blur strength.
- Vehicle and lighting controls, with settings restored when photo mode closes.
- Option to hide the photo-mode interface in screenshots.
- Screenshot capture to PNG.

## Controls

| Action | Default control |
| --- | --- |
| Open photo mode | `Right Ctrl` + `P` |
| Move camera | `W` `A` `S` `D`, `Q` / `E` |
| Rotate camera | Arrow keys or hold and drag with the left mouse button |
| Zoom | Mouse wheel |
| Reset zoom | `0` |
| Open color controls | `C` |
| Open depth-of-field controls | `V` |
| Take screenshot | `Enter` or the on-screen button |
| Close photo mode | `Esc` or the on-screen button |

Photo mode, color controls, depth-of-field controls, and zoom reset actions can be reassigned in the game's control settings.

## Installation

1. Download the mod files or the repository archive.
2. Place the mod folder (the one containing `modDesc.xml`) in your Farming Simulator 25 `mods` folder:
   `Documents\My Games\FarmingSimulator2025\mods`
3. Enable **Photo Mode** in the game's mod selection screen.

## Notes

- Environment and vehicle controls are disabled in multiplayer. Color adjustments depend on the map's supported color profiles.
- Environment, vehicle, color, and depth-of-field settings are restored when photo mode closes.
- Screenshots are saved as PNG files in the game's screenshots folder. If the game does not provide a screenshot directory, the mod uses:
  `Documents\My Games\FarmingSimulator2025\screenshots`
- Screenshot names use the format `FS25_Map_YYYY_MM_DD_HH_MM_SS_01.png`.

The mod interface is available in English, Brazilian Portuguese, and German.

## Modo Foto

Um modo foto com câmera livre para o **Farming Simulator 25**. Prepare a cena, ajuste a imagem e capture screenshots dentro do jogo.

### Recursos

- Câmera livre com velocidade ajustável, zoom pela roda do mouse e opção para redefinir o zoom.
- Controles de horário, clima e estação do ano.
- Ajustes de cor em tempo real: contraste, brilho, saturação, temperatura, gamma e sombras.
- Profundidade de campo com distância de foco e intensidade do desfoque ajustáveis.
- Controles do veículo e das luzes; as configurações são restauradas ao fechar o modo foto.
- Opção para ocultar a interface do modo foto nas capturas.
- Captura de screenshots em PNG.

### Controles

| Ação | Controle padrão |
| --- | --- |
| Abrir o modo foto | `Ctrl direito` + `P` |
| Mover a câmera | `W` `A` `S` `D`, `Q` / `E` |
| Girar a câmera | Setas ou arrastar com o botão esquerdo do mouse |
| Zoom | Roda do mouse |
| Redefinir o zoom | `0` |
| Abrir os controles de cor | `C` |
| Abrir os controles de profundidade de campo | `V` |
| Tirar screenshot | `Enter` ou botão na tela |
| Fechar o modo foto | `Esc` ou botão na tela |

As ações de abrir o modo foto, controles de cor, controles de profundidade de campo e redefinição do zoom podem ser alteradas nas configurações de controles do jogo.

### Instalação

1. Baixe os arquivos do mod ou o arquivo compactado do repositório.
2. Coloque a pasta do mod (a que contém o arquivo `modDesc.xml`) na pasta `mods` do Farming Simulator 25:
   `Documentos\My Games\FarmingSimulator2025\mods`
3. Ative **Photo Mode** na tela de seleção de mods do jogo.

### Observações

- Os controles de ambiente e do veículo ficam desativados no multiplayer. Os ajustes de cor dependem dos perfis de cor compatíveis com o mapa.
- As configurações de ambiente, veículo, cor e profundidade de campo são restauradas ao fechar o modo foto.
- As screenshots são salvas em PNG na pasta de capturas do jogo. Se o jogo não fornecer uma pasta de capturas, o mod usa:
  `Documentos\My Games\FarmingSimulator2025\screenshots`
- Os arquivos seguem o formato `FS25_Map_YYYY_MM_DD_HH_MM_SS_01.png`.
